A concept on real-time arrythmia detection and classification using convolutional neural network in a resource-starved environment.

Original data trained used the [MIT-BIH Arrythmia Database](https://www.physionet.org/content/mitdb/1.0.0/), where the training/testing window split into 1-second windows (360 samples).
